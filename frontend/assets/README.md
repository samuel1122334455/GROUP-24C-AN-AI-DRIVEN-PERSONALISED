# Asset Files

This directory contains app icons, splash screens, and branding assets for Thrive.

## Required Files

- **icon.png** (1024x1024) — App icon (light mode)
- **icon-dark.png** (1024x1024) — App icon (dark mode)
- **splash.png** (1284x2778 recommended) — Splash screen (light mode)
- **splash-dark.png** — Splash screen (dark mode)
- **adaptive-icon.png** (1024x1024) — Android adaptive icon foreground (light)
- **adaptive-icon-dark.png** — Android adaptive icon foreground (dark)
- **favicon.png** (48x48) — Web favicon
- **thrive-light.png** — Thrive wordmark for light backgrounds
- **thrive-dark.png** — Thrive wordmark for dark backgrounds

## Design Guidelines

- Primary brand color: `#2D9CDB` (blue — trust & stability)
- Accent color: `#F2C94C` (gold — wealth & progress)
- Icons should be recognizable at small sizes
- Follow platform guidelines:
  - iOS: [App Icon Guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons)
  - Android: [Adaptive Icons](https://developer.android.com/develop/ui/views/launch/icon_design_adaptive)
